One TV, everyone's phones, and a game that can keep a secret.

Triviall runs party games where the TV shows what is public, each phone shows what is private, and the host runs the room from a third screen.

Open the labRead the docs

Live on this page, from the same engine as the lab. Tap an answer on the phone. Three bots play the other seats.

What you can review today

Trivia

20 questions by default, pulled once per game from the Open Trivia Database, with a bundled set if the network fails. Faster correct answers score more.

Werewolves

5 to 15 players with roles that scale by group size. The runtime narrates every phase. The TV never learns who the werewolves are.

Three views

Display, host, and player each get their own payload from the engine. The lab shows the raw JSON each role receives and flags any secret field on the display.

Tested engine

The game rules are pure and deterministic, so a seed replays identically. Automated tests cover scoring, role isolation, timing, and failure handling.

Not built yet

  • The realtime server and one-click Codespaces startup. Today everything runs in your browser.
  • Joining from real phones with a QR code and room code.
  • Google Cast and TV-browser display for a separate screen.
  • One device acting as host and player at once, across tabs.

The roadmap lists the order, and the verification spike lists what must be tested on real hardware first.
